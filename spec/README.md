# Specification index

AWP separates immutable released specifications from active working drafts.

## Stable release

- [AWP 0.6.0 family overview](../AWP_SPECIFICATION_0.6.0.md)
- [AWP 0.6.0 modules](0.6.0/)
- [AWP 0.6.0 distribution bundle](../dist/0.6.0/AWP-0.6.0.bundle.md)
- [AWP 0.6.0 release notes](../docs/releases/0.6.0.md)

The canonical published bytes are identified by Git tag `v0.6.0`. Released documents, schemas, and tags are immutable.

## Working draft

- [AWP 0.7.0 working draft](drafts/0.7.0/index.md)

Draft contents may change and must not be represented as a published specification. Incompatible changes receive new family, module, and schema versions before publication.

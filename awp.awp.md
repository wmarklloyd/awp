# Staged tree binding

Handoff section 10 defines git-staged-tree-v1: a state binding names the tree recorded by the staged index, so a checkpoint can bind the work before its commit exists and stays current after it. The divergence scan is bounded by the declared scope.

Planning update: [Cooperation Contracts 0.1](spec/drafts/0.8.0/cooperation-contracts.md) defines COOP-0, COOP-1, and COOP-2 as AWP 0.8's single cumulative cooperation and coordination conformance ladder. COOP-1 combines portable collaboration, deterministic projection, declared guarded-scope blocking, bounded participant leases, checkpoint recovery, and decision-owned feedback loops. COOP-2 incorporates semantic awareness, integration assurance, authenticated protected mutation, fencing, and a scalable operating envelope. Current tools do not yet establish complete COOP-1 or COOP-2 conformance.

Planning update: the user requested an architecture that smaller models can implement. See [Model participation architecture and implementation plan](docs/model-participation-architecture.md). This informative proposal defines five model operations, delegated processing responsibilities, bounded context, receipt-based publication, freshness, and recoverable checkpoint/exit behavior. The responsibility matrix in [docs/model-participation-matrix.md](docs/model-participation-matrix.md) assigns each operation and deterministic COOP-1 behavior to its owning component. Operation state machines are documented in [docs/model-participation-state-machines.md](docs/model-participation-state-machines.md), and ten worked conversations are documented in [docs/model-participation-conversations.md](docs/model-participation-conversations.md). The local adapter has a limited `checkpoint` continue path: it records a durable receipt only when a supplied capsule frontier matches the ledger frontier, and keeps exit pending until terminal intent, capsule projection, and presence-release bindings are implemented. The architecture does not establish complete COOP-1 conformance or change the governing capsule version.

Planning update: the experimental participation schema and structural examples define the five model-facing request operations, a common operation response, and publication receipts. The local adapter implements read, announce, publish, interact, and a limited checkpoint path; complete COOP-1 composition and host authority remain outstanding.

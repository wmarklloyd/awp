# Security policy

AWP is currently a specification and validation-tool project. There is no production service or privileged runtime in this repository.

Security-sensitive reports may concern unsafe parsing guidance, path traversal, active-content handling, authority confusion, schema-validation bypass, malicious fixtures, or vulnerabilities in the supplied tools.

Report vulnerabilities privately through GitHub Security Advisories for this repository when available. Do not include secrets, exploit payloads, or personal information in a public issue. If private reporting is unavailable, open a minimal public issue requesting a private contact channel without disclosing the vulnerability.

The editor will acknowledge a report, assess affected versions, preserve reporter attribution when requested, and publish a fix or advisory appropriate to the project’s experimental status. AWP records and signatures do not grant execution authority; implementations remain responsible for local policy, sandboxing, authentication, and authorization.

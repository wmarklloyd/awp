# ADR 0003: Retain GPL-3.0-only pending licensing review

- **Status:** Accepted
- **Date:** 2026-09-03

## Context

Interoperability specifications often separate documentation and reference-code licenses. Relicensing without confirming ownership and contribution terms would create more ambiguity than it resolves.

## Decision

Retain GPL-3.0-only consistently for the current repository. Document the potential CC BY 4.0 and Apache-2.0 split as a future legal-review question rather than implying that it has occurred.

## Consequences

All current metadata identifies GPL-3.0-only. A later licensing change requires an explicit decision, complete license texts, contributor consent where applicable, and updated release metadata.

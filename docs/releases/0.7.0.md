# AWP 0.7.0 Release Notes

**Status:** Stable exploratory release  
**Canonical tag:** `v0.7.0`  
**Successor to:** AWP 0.6.0  
**License:** GPL-3.0-only

AWP 0.7.0 promotes the validated working draft to the next stable exploratory specification family. It does not claim that the protocol has a production implementation or that the coordination model has demonstrated agent effectiveness.

## Highlights

- Makes a single `.awp.md` capsule the portable discovery unit, with embedded format, discovery mode, workstate identity, frontier, checkpoint, and exact specification binding.
- Generalizes Coordination from repository-centric state to arbitrary state spaces and domain-specific selector profiles, including digital, physical, spatial, documentary, analytical, and mixed work products.
- Defines portable Security guardrails with provenance, authority basis, receiver enforcement, propagation, and composition rules that apply to solo and collaborative operations.
- Adds a Core `consultation` record for bounded cross-model, human, or specialist advice with portable context and response provenance.
- Adds structural schemas, conformance fixtures, deterministic requirement inventory, generated bundle coverage, and repository-integrity checks for these capabilities.

## Compatibility and limitations

0.7.0 is intentionally incompatible with the 0.6.0 working-state interpretation where the changed module semantics apply. Readers must use the declared governing specification and module versions; they must not infer compatibility from filenames or silently substitute another specification.

Coordination remains normative but experimental. The repository contains specification validation and a deterministic synthetic instrumentation pilot, not an independent interoperability trial, production reader/writer, complete semantic-scope analyzer, live coordination service, or C3 enforcement implementation. Portable guardrails describe policy state; enforcement remains the responsibility of the receiving runtime or protected adapter.

The 0.6.0 release remains available unchanged at [`v0.6.0`](https://github.com/wmarklloyd/awp/tree/v0.6.0).

# Licensing rationale

The repository currently uses GPL-3.0-only, as recorded in `LICENSE`, package metadata, and citation metadata. No file is implicitly available under a different license.

Before a stable 1.0 specification, the editor should obtain legal advice on separating specification text from executable assets. A possible future policy is CC BY 4.0 for specification prose and Apache-2.0 for schemas, fixtures, validators, and reference implementations. Such a change requires confirmation that the editor holds the necessary rights, explicit license texts, contribution terms, and a documented relicensing decision.

This note is informative and does not perform or promise relicensing.
